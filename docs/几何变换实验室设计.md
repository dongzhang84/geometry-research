## 1. 这个 App 是什么、不是什么

<b>不是</b>用来发现新定理的。扫描、筛子、证明那套流水线是另一回事，在
`一般四面体定理扫描.md` 和 `垂心四面体定理扫描.md` 里。

<b>是</b>用来让人<b>看见定理是怎么来的</b>。现有的 `docs/*.md` 是写给会读数学的人
看的；`explore/nine-point.html` 上那些演示（九点二次曲线、沿外接圆、七点球定理、
十三点球、欧拉线共轭平面……）已经是雏形，但它们各自独立，彼此之间没有线索。这个
App 要补的就是那条线索。

## 2. 方向一：几何变换实验室

<b>一句话：</b>拖动三角形的顶点，实时看<b>位似和反演</b>怎样把一个图形变成另一个，
欧拉线、九点圆、费尔巴哈相切都从这个过程里长出来。

内容骨架直接取自 `docs/变换群观点下的几何定理.md`。

### 2.1 三幕

<b>第一幕：欧拉线 = 一个位似。</b>
位似 h(G, −1/2) 把 △ABC 送到中点三角形。中点三角形的垂心正是 △ABC 的外心，所以
这个变换把 H 送到 O —— O、G、H 共线、且 HG : GO = 2 : 1，整条欧拉线就是这一个
变换的产物。界面上：拖动顶点时，用一根动画线段把 H 沿着变换轨迹送到 O。

<b>第二幕：九点圆 = 两个位似。</b>
h(G, −1/2) 和 h(H, 1/2) 把外接圆送到<b>同一个</b>圆，这就是九点圆：前者给出三条边
的中点，后者给出三个欧拉点，而垂足是两者的交会。界面上：两个位似各用一种颜色，
同时播放，两个像重合时停住。

<b>第三幕：费尔巴哈相切 = 一个反演。</b>
以边中点 M_a 为心的某个反演，把内切圆和九点圆同时送到一对平行线之间，相切关系在
反演下不变，于是「九点圆与内切圆相切」被还原成一件几乎显然的事。界面上：切换到
反演视角，看两个圆被拉直。

### 2.2 一根滑块：克莱因层级

这是这个实验室区别于普通几何画板的地方。顶部一根滑块，把所用的变换群从小往大放：

| 群 | 九点圆变成什么 | 还剩什么 |
|---|---|---|
| 相似群 | 九点圆 | 全部成立 |
| 仿射群 | 九点二次曲线 | 中点、重心还在，圆没了 |
| 射影群 | 十一点二次曲线 | 只剩共线、交比 |
| 反演群 | 费尔巴哈相切的真正位置 | 相切还在，圆心没了 |

滑块每走一格，图形连续形变，旁边一句话说明<b>哪条性质刚刚失效、为什么</b>。这是
把那篇文档的主线（「每个定理真正属于哪一层」）变成可以用手拖的东西。

### 2.3 交互清单

- 拖动 A、B、C 三个顶点，所有导出对象实时重算；
- 图层开关：中线 / 高 / 外接圆 / 九点圆 / 内切圆 / 欧拉线 / 西姆松线；
- 变换播放条 t ∈ [0, 1]，可暂停、可倒放；
- 群层级滑块（2.2）；
- 每一幕配一句话，不超过两行，点「为什么」展开到对应的 `docs/*.md`。

## 3. 方向二：定理脉络地图

<b>一句话：</b>节点是定理，边是「谁推出谁」，点开一个节点就在旁边放那条定理的小
动画。

- <b>节点和边</b>从 `九点圆定理系统.md` 的关系图来，已经是现成的；
- <b>出处</b>从 `geometry_of_remarkable_elements/`（Mihalescu 第 1 章，1.1–1.168，
  每条都带原始出处和年份）来，可以给每个节点标上「谁、哪年、哪本书」；
- 点节点 → 右侧调用方向一的引擎播那条定理的动画。

所以这两个方向不是二选一：<b>地图是导航，实验室是内容。</b>地图单独做意义不大，
实验室单独做则缺少一个让人知道「还有什么」的入口。建议<b>先做实验室的三幕</b>，
地图作为第二步。

## 4. 技术路线

本仓库已有的 `explore/geometry.js` 和 `explore/nine-point.js` 就是这个引擎的前身：
纯静态、无构建、Vercel 直接部署。实验室可以在同一套代码上长出来，新增的主要是
<b>变换的动画插值</b>和<b>群层级的连续形变</b>这两件事。

设计、定理取舍，以及事后审稿。

`geometry-atlas.vercel.app` 上。

两条路做出来的东西可以是同一个，<b>节奏完全不同</b>。这是开工前要先定的唯一一件事。
