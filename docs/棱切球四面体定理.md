# 棱切球四面体的定理（草稿）

棱切球四面体（circumscriptible tetrahedron，即 tetrahedron with a midsphere；Fox 等人称 “4-ball tetrahedron”；又叫 Crelle 四面体）这一轮做了共线、共面、共圆、共球四层扫描，筛到最后剩下的结果都整理在这里。整理于 2026 年 11 月 19 日，11 月 20 日修订。脚本和独立复核见文末「代码和数据」。

新定理在一般四面体里都**不成立**，都要用到「存在棱切球」这个条件。

## 记号

- 棱切球四面体等价于四个两两外切的球 Σ_i，球心为顶点 V_i，半径为切长 t_i，棱长 |V_iV_j| = t_i + t_j。记 T = Σt_i，s = Σ1/t_i。
- T_ij 是 Σ_i 与 Σ_j 的切点，也就是棱 V_iV_j 与棱切球的切点。
- 棱切球记作 μ，球心 M，半径 ρ。M 是四个顶点球的根心，μ 与四个顶点球都正交。
- Z 是 Zeeman 点：三条对棱切点连线 T₀₁T₂₃、T₀₂T₁₃、T₀₃T₁₂ 的公共点，重心坐标为 (1/t_i)。直线 MZ 是 Soddy 线。
- σ1、σ2 是两个 Soddy 球（与四个顶点球都相切的球）。s1_i、s2_i 分别是它们与 Σ_i 的切点。
- G：重心；O、R：外心、外接球半径；K：类似重心，重心坐标为 (S_i²)。由 Heron 公式，S_i² ∝ (T − t_i)/t_i。
- P*、Pᵗ：点 P 的等角共轭点（重心坐标 S_i²/p_i）和等截共轭点（重心坐标 1/p_i）。
- F：Fermat 点，即到四个顶点距离之和最小的点；d_i = |FV_i|。

## 一、新定理（已证明）

### 定理 1：中心平面　The Central Plane

**陈述**：G、O、K、M、Z 五点共面。两个 Soddy 球心在直线 MZ 上，所以也在这个平面上。

**证明**：只需证明这五个点的重心坐标（不必归一化）都落在由 1、1/t_i、1/t_i² 张成的三维向量空间里。

- G = (1)，Z = (1/t_i)，K ∝ (T/t_i − 1)。
- O 和 M 用同一个引理。记 E 为棱长平方矩阵，E_ij = (t_i + t_j)²（i ≠ j），E_ii = 0，于是 E = −4·diag(t²) + t²1ᵀ + 2ttᵀ + 1t²ᵀ。
  - 外心满足 E·o = c·1。逐分量写出来就是 −4t_i²o_i + t_i²(Σo) + 2t_i(t·o) + (t²·o) = c，所以 o_i ∈ span{1, 1/t_i, 1/t_i²}。
  - 棱切球心满足 E·m = c′·1 + (t_i²)，同理 m_i ∈ span{1, 1/t_i, 1/t_i²}。实际算出来是 m_i ∝ s/(2t_i) − 1/t_i²。

五个点落在同一个三维向量空间里，在射影意义下就是同一个平面。∎

**验证**：证明是手算；另在 40 组随机有理切长上精确检验成立（独立复核）。数值上，旁切四面体的重心也在这个平面上（待证）。

**文献**：Fox–Oldknow–Rigby–Zeeman 读过的是两份：*Math. Gazette* 92 (2008) 的 Part 1 正式版 PDF，和 2005 年 7 月的 21 页完整版（Oldknow 网站存档，含全部结果和证明）。Part 2 的正式版没有看到。这两份里都没有这个平面：其中的 Zeeman plane 是 Z 的极平面，平面族 K_D 过 Soddy 线、垂直于某个面，两者都不是它。Rabinowitz 2021 没有核过。

### 定理 2：GM 共轭平面　The GM Conjugate Plane

**陈述**：对直线 GM 上任意一点 P，P* 和 Pᵗ 都与直线 GM 共面。

**证明**：sympy 完整符号证明（四点共面行列式的分子恒为 0，用时 235 秒）。手算证明待补，可以参照垂心四面体那一轮定理 2 的 Vieta 证法。

**说明**：垂心四面体里有同一类型的结果（欧拉线共轭平面）。这里对应的直线换成了 GM。

### 定理 3：八点球　The Eight-Point Sphere

**陈述**：下面八个点共球：
- 四个棱切点 T₀₁、T₀₂、T₁₃、T₂₃；
- σ1 与 Σ1、Σ2 的切点 s1_1、s1_2；
- σ2 与 Σ0、Σ3 的切点 s2_0、s2_3。

也就是说，σ1 取棱 12 的两端，σ2 取对棱 03 的两端。按对棱的选法，一共有 6 个这样的球。

**证明**（CC 给出思路，我补全了计算）：
1. 以 T₁₂ 为中心反演。Σ1 与 Σ2 在这一点相切，所以变成两张平行平面，记间距为 h = 2r。
2. Σ0、Σ3、σ1、σ2 都和 Σ1、Σ2 相切，所以变成夹在两平面之间、半径都是 r 的四个球，球心都在中间平面上。
3. 相切关系是：Σ0 与 Σ3 相切，σ1、σ2 都与 Σ0、Σ3 相切。所以在中间平面上可以取坐标 c0 = (−r, 0)，c3 = (r, 0)，σ1 的球心为 (0, √3r)，σ2 的球心为 (0, −√3r)，四个球心构成一个菱形。
4. 取 O′ = (0, √3r/3)，它是三角形 c0c3σ1 的中心。
   - T₀₁、T₀₂、T₁₃、T₂₃、s1_1、s1_2 的像，都是半径为 r 的小球与两张平面的切点，到 O′ 的距离平方为 4r²/3 + r² = 7r²/3。
   - s2_0 的像是 σ2 球心与 c0 连线的中点 (−r/2, −√3r/2)，到 O′ 的距离平方为 r²/4 + 25r²/12 = 7r²/3。s2_3 与它对称。
5. 八个像点在同一个球上，半径平方为 7r²/3 = 7h²/12。这个球一般不经过反演中心，所以反演回去，原来的八个点也共球。∎

**退化**：像球恰好经过反演中心时，八个原像点退化为共面。

**验证**：60 位精度，20 个新样本；另在 40 组随机有理切长上、于二次扩域 ℚ(√D) 里精确检验成立（独立复核）。注意四个棱切点本身共圆（两条对棱切点连线交于 Z），「共圆四点加任一点」恒共球，所以检验时必须用三个棱切点加一个 Soddy 切点定球，再检验其余四点。

**文献**：Fox 等人原文（上述两份）没有。这个证明比较初等，正式定稿前还要再查一遍 Altshiller-Court 等经典著作。

### 定理 4：四点共圆　A Concyclic Quadruple（原候选 C2，CC 记作 E）

**陈述**：设 A、B 是直线 OM 与外接球的两个交点，K′ 是 K 关于棱切球的反演点，G′ 是 G 关于外接球的反演点。那么 K′、G′、A、B 四点共圆，这个圆落在中心平面（定理 1）里。

**说明**：CC 原来的写法还多了一个点 2O − G，它是自动在圆上的：过 A、B 的圆，O 对它的幂都等于 −R²。每个顶点对应的那个球（扫描中的 #23）都由这一条推出。

**证明**：
1. 由定理 1，O、M、G、K 共面；K′ 在直线 MK 上，G′ 在直线 OG 上，所以四点都在中心平面里。
2. 在这个平面里以 O 为原点，x 轴取直线 OM，则 A、B = (±R, 0)。过 A、B 的圆是一族 x² + y² − 2λy − R² = 0，点 X 所在那个圆的参数为 λ(X) = (|OX|² − R²)/(2y(X))。
3. 把 X − O 写成 α(M − O) + β(G − O)，则 y(X) = β·y(G)。对 G′ 有 β = R²/|OG|²，算出 λ(G′) = (R² − |OG|²)/(2y(G))。
4. 所以命题等价于一个只含切长的有理恒等式：|OK′|² − R² = β(K′)·(R² − |OG|²)。
5. 在有理函数域 ℚ(t₀, t₁, t₂, t₃) 上精确计算（Python，sympy 的有理函数域，用时 31 秒），残差恒为 0。∎

**非退化条件**：O、M、G 不共线（否则中心平面不确定），K ≠ M。

**验证**：60 位精度，20 个样本；8 组随机有理数精确为零；符号恒等式成立；独立复核 40 组精确成立。

**文献**：未找到。

### 定理 5–7：三个五点球　Three Five-Point Spheres（原候选 C6–C8，CC 记作 H1–H3）

记 X1 为面三角形的内心，X11 为面三角形的 Feuerbach 点。在棱切球四面体的面 V_jV_kV_l 上，边长为 t_k+t_l 等，半周长减边长就是 t_j，所以这两个点的重心坐标都是切长的有理函数：X1 = (t_k+t_l : t_j+t_l : t_j+t_k)，X11 = (t_j(t_k−t_l)² : t_k(t_j−t_l)² : t_l(t_j−t_k)²)。

- **定理 5（原 C6）**：下面五点共球：T₁₂；对棱切点连线 T₀₁T₂₃ 和 T₀₂T₁₃ 的中点；含棱 12 的两个面 V0V1V2、V1V2V3 的 Feuerbach 点。每条棱给出一个这样的球。
- **定理 6（原 C7）**：下面五点共球：V1；面 V0V1V2 的内心；T₁₃；T₀₁T₂₃ 的中点；面 V0V1V3 的 Feuerbach 点。同类共 24 个。
- **定理 7（原 C8）**：下面五点共球：棱 02 两侧两个面 V0V1V2、V0V2V3 的内心；棱 02 的中点 m₀₂；m₀₂ 在直线 V1V3 上的垂足；T₁₃。每条棱给出一个这样的球。

**证明**：五个点都是切长的有理函数。三维空间里五点共球（或共面）的充要条件是这五点两两距离平方组成的 5×5 矩阵行列式为零。在有理函数域 ℚ(t₀, t₁, t₂, t₃) 上精确计算，三条的行列式都恒为 0，每条用时 1 到 2 秒。另外，在随机有理样本上五点的重心坐标秩为 4，说明一般情况下不共面，是真正的球。∎

**能否化归到面三角形**：不能。每条都同时用到两个面上的点，或者用到面外的点（对棱切点连线的中点、对棱上的垂足），所以不是单个三角形的事实，ETC 不适用。这和 #35–#37 不同，那三类本身就落在一个面上。

**验证**：60 位精度，20 个样本；随机有理样本精确成立；符号恒等式成立；独立复核三条各 40 组精确成立。

**文献**：未找到。

### 定理 8：引理 D　The Homothety Lemma（原候选 C4）

**陈述**：取对棱对 p = (ij | kl)。过 Z 和另外两条对棱切点连线中点的圆记作 Γ_p。设 E_kl 是顶点球 Σ_k、Σ_l 的外位似中心（t_k ≠ t_l）。那么：
1. E_kl 在 Γ_p 所在的平面上；
2. E_kl 对 Γ_p 的幂，等于以 E_kl 为中心、互换 Σ_k 与 Σ_l 的那个反演的幂，即 (t_l/t_k)·pow(E_kl, Σ_k)。

E_ij 也满足同样的结论。

**推论**：任何与 Σ_k、Σ_l 同种方式相切（都外切，或都内切）的球，它的两个切点与 Γ_p 共球。理由是：这两个切点关于 E_kl 是反相似点，它们到 E_kl 的距离之积就是上面那个反演的幂。具体地：取过 Γ_p 和第一个切点的球。由结论 1、2，E_kl 对过 Γ_p 的每个球的幂都等于这个反演的幂；而两个切点与 E_kl 共线、到 E_kl 的距离之积也是这个幂，所以第二个切点就是这条直线与球的另一个交点，自动在球上。CC 扫描到的 #26、#27 是取两个 Soddy 球的特例。

**证明**：所有点都是切长的有理函数。在 ℚ(t₀, t₁, t₂, t₃) 上精确计算：
- 共面：用 Gram 行列式判定；
- 幂相等：直接比较两个有理式。

三个对棱对、每对两个位似中心，6 种情形全部恒等成立，用时 17 秒。∎

**验证**：独立复核 40 组随机有理切长精确成立（含推论：取 σ1 的两个切点）。

**退化**：t_k = t_l 时 E_kl 在无穷远。

**文献**：「公切球的两个切点关于外位似中心互为反演」是经典结果；关于 Γ_p 的部分没有找到出处。

### 定理 9：引理 B　The Orthogonal-Sphere Lemma（原候选 C5）

**陈述**：过 T_ij、且与两个 Soddy 球都正交的球，一定经过对棱上的切点 T_kl。

**证明**：分两步。

**(a) 两个 Soddy 球的根平面就是 Zeeman 平面（已知）。** Zeeman 平面指 Z 关于棱切球 μ 的极平面，记作 Π_Z。这一步 Fox 等人已有：Part 1 §4.4 给出 Zeeman 平面的方程 ax + by + cz + dw = 0，§5.6 说 μ、σ、σ′ 的公共根平面也是 ax + by + cz + dw = 0；21 页完整版 3.51 的证明里直接写了 “The polar of Z is Γ, the radical plane of the two Soddy spheres”。下面是我们的独立推导，供完整起见。Soddy 球半径记作 r_σ，ρ 仍是棱切球半径。
1. 把 Soddy 球心写成 S = M + λ(Z − M)。四个相切条件 |S − V_i| = t_i + r_σ 两两相减，得到三个关于 r_σ、λ 的线性关系，它们恒等一致。这说明 Soddy 球心在 Soddy 线 MZ 上，这一点 Fox 等人已有。
2. 代回一个条件，得到 λ 的二次方程 Q(λ) = 0。
3. 另一方面，「σ 与 μ 的根平面是 Π_Z」等价于 r_σ² = λ²|ZM|² − 2λρ² + ρ²。把它整理成二次式 P(λ)，精确计算表明 P 与 Q 成比例。
4. 所以对两个 Soddy 球都有 pow(X, σ) − pow(X, μ) ∝ (X − M)·(Z − M) − ρ²。也就是说，σ1、σ2、μ、Π_Z 属于同一个球束。

**(b) 化成平面问题。** 与 σ1、σ2 都正交，等价于与这个球束的每个成员正交，也就等价于与 μ 正交、且球心在 Π_Z 上。过 T_ij 且与 μ 正交的球，球心在 μ 于 T_ij 处的切平面上，因为 T_ij 在 μ 上。所以这类球的球心都落在一条直线上：切平面与 Π_Z 的交线。命题等价于这条交线落在 T_ijT_kl 的中垂面里，也就是三张平面共线。在 ℚ(t) 上精确计算，三张平面的系数矩阵秩为 2，各种对棱情形都成立。∎

**验证**：独立复核 40 组随机有理切长精确成立（(b) 的三面共线）。

**等价形式**：T_ij、T_kl 与 Soddy 球束的两个极限点四点共圆。

**文献**：(a) 已知，出处见上（Fox 等人 Part 1 §4.4、§5.6，完整版 3.51 的证明）。新的只是引理 B 本身，文献里没有找到。

### 定理 10：Soddy 五点球　The Soddy Five-Point Sphere（原候选 C3，CC 记作 G）

**陈述**：取对棱对 p = (ij | kl)，取棱 kl，取一个 Soddy 球 σ（球心 S，半径 r_σ）。下面五点共球：
- Z；
- 对棱切点连线 T_ijT_kl 的中点；
- σ 与 Σ_k、Σ_l 的两个切点；
- M 关于 σ 的反演点。

两个 Soddy 球都成立。每个对棱对、每条棱各给出一个，一共 2 × 3 × 2 = 12 个球。

**说明**：Z 和这个中点都在弦 T_ijT_kl 上；Z、M、S 和 M 关于 σ 的反演点都在 Soddy 线上。推广到只与两个或三个顶点球相切的球时，命题不成立（偏差 0.12 到 0.16）。

**证明**：Soddy 球的坐标要开根号，所以把它放进二次扩域里算。
1. 由定理 9 的 (a)，S = M + λ(Z − M)，r_σ = a + bλ，其中 a、b 是切长的有理函数，λ 满足二次方程 Q(λ) = 0。
2. 在 ℚ(t)[λ]/(Q) 中做精确运算，元素都写成 x + yλ。这样两个 Soddy 球是同时处理的。
3. 五个点的坐标都属于这个域。它们两两距离平方组成的 5×5 行列式在这个域里恒为 0，用时 122 秒。
4. 其余各种情形都由下标置换得到，因为 t 是一般符号，所以只需算一种情形。
5. 随机样本上五点不共面，所以这是真正的球。∎

**验证**：独立复核在 ℚ(√D) 里 40 组精确成立，两个 Soddy 球都算；先核对了构造出的球确实与四个顶点球相切。

**文献**：未找到。

## 二、定理 11（原候选 C1，已证明）

### 定理 11：Fermat 共线　The Fermat Line

**陈述**：F、F*、M 三点共线。

**验证**：9 个样本，50 到 60 位精度。三角形里的类比不成立，一般四面体里不成立，换成加权 Fermat 点也不成立。

**引理（对任意四面体都成立，已证明）**：直线 FF* 恰好由满足下面条件的点 Y 组成：|YV_i|² − |FV_i|² 是 |FV_i| 的一次函数。证明的关键是：四个单位向量 (V_i − F)/d_i 之和为零，它们的 Gram 矩阵在 Klein 四元群下不变，于是伪逆的对角线是常数。

**证明**：
1. **化成一个关于 d_i 的命题。** 由于 |MV_i|² = t_i² + ρ²，有 |MV_i|² − d_i² = ρ² − (d_i² − t_i²)。由引理，只需证明 **F 对四个顶点球的幂是 F 到顶点距离的一次函数**：d_i² − t_i² = α + βd_i。等价地，4×3 矩阵 [1, d_i, d_i² − t_i²] 的秩 ≤ 2，即它的四个 3×3 子式 h_1, …, h_4 都为零（d_i 不全相等时）。
2. **Fermat 点的方程。** 记 u_i = (V_i − F)/d_i，Fermat 点满足 Σu_i = 0。由 |u_0 + u_1|² = |u_2 + u_3|² 得 cos∠V_0FV_1 = cos∠V_2FV_3，记为 a；同理对另两组对棱有 b、c；由 |Σu_i|² = 0 得 a + b + c = −1。也就是说，对棱在 F 处张的角相等。
3. **代入棱长。** 由余弦定理，(t_i + t_j)² = d_i² + d_j² − 2c_ij d_i d_j。用每组对棱消去 a、b、c，再用 a + b + c = −1，得到四个只含 d、t 的多项式方程 g_1 = … = g_4 = 0（各乘以 d 的单项式去分母）。
4. **理想成员关系。** 记 A = Σ_i d_i ∏_{j≠i} t_j（即 t₀t₁t₂t₃ · Σd_i/t_i），D = d₀d₁d₂d₃。在多项式环 ℚ[d₀, …, d₃, t₀, …, t₃] 里，Singular 算出
   A · D · h_k ∈ (g_1, g_2, g_3, g_4)，k = 1, …, 4。
   这是多项式恒等式，t 是变量，不是特殊值，所以没有「对一般 t」的例外。用时约 2 秒。对 h_1 导出了显式证书 A·D·h_1 = Σ L_k g_k，用 sympy 独立展开核对，残差为 0（6 秒）。另外，A·h_k 和 D·h_k 单独都不在理想里，说明两个因子都不能省：D 排除 d_i = 0 的退化解，A 排除 6 组「带符号的伪 Fermat 点」（四个方向两正两负，满足 Σd_i/t_i = 0）。
5. 真正的 Fermat 点在四面体内部，d_i > 0，t_i > 0，所以 A > 0、D > 0，于是 h_k = 0，第 1 步的条件成立。d_i 全相等是一个真子簇，那里由连续性得到同样的结论。∎

**数值核对**：6 个随机样本上，真 Fermat 点满足 g_1–g_4（50 位精度残差 ≤ 10⁻⁴⁹），A 在 3.9 到 4.8 之间，确实为正。

## 五、方法上的两个教训（写进扫描报告和论文附录）

1. **大半径球盲区**：在扫描样本上，半径远大于 R 的球几乎是平面，第一步检测不出来。这次把几个样本的结果取并集，部分补上了。这种很大的假球能通过第二步检查，只有在新样本上重验时才会被筛掉。垂心那一轮可能有同样的问题，需要核一下前两篇论文附录里关于扫描完整性的说法。
2. **近重合假阳性**：样本太规则时，会出现两个点几乎重合（比如旁切 Monge 点离内心只有 10⁻⁴），从而产生假关系。对策是用不规则样本，并加一道近重合过滤。
