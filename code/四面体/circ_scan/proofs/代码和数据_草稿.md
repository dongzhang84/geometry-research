## 附录：代码和数据（草稿）

格式参照《垂心四面体定理扫描》附录 A。

- **扫描代码**在 `code/四面体/circ_scan/`，按约定不入库，只留在本地。
- **证明脚本**在 `code/四面体/circ_scan/proofs/`，入库，供复现。

依赖：Python 3、numpy、scipy、numba、mpmath、sympy。

### 一、点集（云端生成，本地只读，不要改）

| 文件 | 内容 |
|---|---|
| `circ_points.pkl` | 1,183 个中心 + 307 个轨道点 = 1,490 个点，在 6 个不规则棱切球四面体上的坐标 |
| `gen_lib.pkl` | 同一套作法在 6 个随机一般四面体上的坐标，用来去掉一般四面体里也成立的关系 |
| `rv_pts.pkl` | 同 1,490 个点在 10 个新样本上的坐标，用于复核 |
| `tetlib.py`、`orbits.py`、`build.py`、`cbuild.py`、`cbuild2.py`、`cgen.py`、`irr.py`、`verify1.py` | 生成点集的代码（切长 `tlen`、棱切球心 `Mcen`、Soddy 球 `soddy`） |
| `cpoints.py` | 读入点集，提供 `canon()`（按顶点对称合并）等 |
| `cscan_lines.pkl`、`cscan_planes.pkl` | 共线、共面扫描结果（云端） |

### 二、五点以上共球扫描（本地，Claude Code）

| 文件 | 内容 |
|---|---|
| `csph.py` | 扫描。第 1 步在样本 0、1、5 上找候选并取并集（numba 并行），第 2 步在 6 个样本上复核，再做完整性检查。由 `ortho_scan/ospheres.py` 改来，算法和容差不变 |
| `csph_check.py` | 完整性检查：三对关于外接球、内切球、棱切球互为反演的点必共球，看扫描有没有漏掉 |
| `csph_classify.py` | 分类筛子（多进程）。已知球 10 个：外接球、内切球、十二点球、棱切球、两个 Soddy 球、四个顶点球 |
| `csph_inherit.py`、`cinherit.py` | 去掉一般四面体里也成立的球 |
| `rv2.py` | 在 10 个新样本上复核，去掉近重合 |
| `csph_final.py`、`cshow_spheres.py` | 按对称合并，输出 `csph_left.md`（37 类） |
| `csph_1490.log`、`csph_1490_src01.log`、`csph_cls_1490.log` | 运行日志（`src01` 是只用样本 0、1 的那次，完整性检查漏了 1 组） |
| `csph_cls_1490.pkl`、`spec_sphere.pkl`、`rv_sphere.pkl`、`csph_final.pkl` | 各步结果 |
| `csph_raw_1490.pkl` | 中间结果（358 MB），可由 `python3 csph.py` 重新生成（16 核约 50 分钟） |
| `csph_汇报.md` | 扫描汇报：各步数字、37 类的逐类检查 |

跑法：

```
python3 csph.py && python3 csph_classify.py csph_raw_1490.pkl
python3 csph_inherit.py csph_cls_1490.pkl && python3 rv2.py sphere && python3 csph_final.py
python3 cshow_spheres.py csph_final.pkl > csph_left.md
```
