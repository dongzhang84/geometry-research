# 《棱切球四面体定理》独立复核记录

Claude Code，2026-11-20，本机（macOS，Python 3.12）。

云端的证明脚本包到这时还没有到本地，所以没有按原计划去重跑云端脚本，而是**另写了一套独立的精确复核**：`independent/exact_check.py`。它和云端脚本不共用任何代码。云端脚本到了以后，再补「重跑云端脚本」一节。

## 方法

- 切长 t 取随机有理数，所有点都用重心坐标表示。
- 距离平方用重心距离公式计算，棱长平方取 d_ij² = (t_i + t_j)²，全程精确有理运算，没有浮点。
- 含 Soddy 球的定理（3、10）在二次扩域 Q(√D) 里精确运算，D = ((Σ1/t_i)² − 2Σ1/t_i²)/12。Soddy 球心 ∝ M + ε√D·Z（ε = ±1，Fox 等 5.4），曲率 = ½Σ1/t_i + 3ε√D（Fox 等 5.1）。脚本先核对 Soddy 球心到四个顶点的距离精确等于 t_i + r，再做检验。
- 判据：
  - 共球或共面：5 点距离平方矩阵的行列式为 0；
  - 共面：4 个重心坐标的行列式为 0；
  - 三面共线：三个仿射函数在四个顶点上的取值矩阵秩为 2。
- 这是有理函数恒等式的随机检验（Schwartz–Zippel 型）：在大量随机有理点上精确为零，恒等式不成立的概率可以忽略。它不能代替符号证明，但和云端的符号证明完全独立。

## 对照组（`independent/controls.py`）

每条换掉一个点，检验都应当不成立。7 组对照「成立」次数都是 0：

| 对照 | 换掉的点 |
|---|---|
| 定理 1 | K 换成 (1/S_i²) 权重点 |
| 定理 2 | P 取直线 GO 上的点 |
| 定理 5 | Feuerbach 点换成面内心 |
| 定理 7 | T13 换成 T12 |
| 定理 9 | T_kl 换成相邻棱的切点 |
| 定理 3 | σ2 的切点换到 Σ1 上 |
| 定理 10 | 棱和对棱对配错 |

写对照时发现过一个陷阱，已经修正：定理 3 的四个棱切点本身共圆，「共圆四点 + 任一点」恒共球。第一版检验因此是恒真的，对照组暴露了这一点。改成用三个切点加 s1_1 定球之后，对照组正确地不成立。云端脚本如果也用了「四个切点 + 一点」的行列式，会有同样的问题，重跑时要留意。

## 补充：C1（Fermat 共线）的证明，2026-11-20

C1 已证明，成为定理 11。

- **方法**：用「对棱在 F 处张角相等、三个余弦之和 = −1」把 Fermat 点写成 4 个只含 d、t 的多项式方程 g_1–g_4。在 ℚ[d₀..d₃, t₀..t₃] 里（t 是变量，不是特殊值）验证 A·D·h_k ∈ (g_1..g_4)，其中 h_k 是 [1, d_i, d_i² − t_i²] 的四个 3×3 子式，A = Σd_i∏_{j≠i}t_j，D = ∏d_i。
- **结果**：k = 1–4 全部成立，Singular 4.4.1 用时约 5 秒（`C1/c1_ideal.sing`）。A·h_k、D·h_k 单独都不成立。
- **独立核对**：导出 h_1 的证书（`C1/c1_cert.txt`），用 sympy 展开 A·D·h_1 − ΣL_k g_k，残差为 0，用时 6.3 秒（`C1/c1_verify_cert.py`）。
- **前提的数值核对**：6 个样本上，真 Fermat 点满足 g_1–g_4，残差 ≤ 10⁻⁴⁹，A > 0（`C1/c1_numeric_check.py`）。
- **过程中失败的路线**：把 t 当参数域 ℚ(t) 做 std，跑了 40 分钟没算完，已停掉。改成把 t 当环变量以后只要 2 秒。
- **环境**：Singular 用 brew 安装。装完以后 PATH 里的 python3 变成了 Homebrew 版，那个版本没有 sympy。复核时用的是 `/Library/Frameworks/Python.framework/Versions/3.12/bin/python3`。

## 补充：定理 1–10 的符号证明，2026-11-20

`independent/symbolic_check.py`：把 `exact_check.py` 的有理数换成有理函数域 ℚ(t1, t2, t3, u)（t0 = 1，相似不变）。含 Soddy 球的两条（定理 3、10）在 ℚ(t)(√D) 里算；D 不是平方，所以这是域。定理 2 里 P = (1−u)G + uM，u 是符号。这样随机检验就成了符号恒等式。结果见 `independent/symbolic_check.log`：

| 2 | 恒等成立 | 8.3 s |
| 3 | 恒等成立 | 14.6 s |
| 4 | 恒等成立 | 4.1 s |
| 5 / 6 / 7 | 恒等成立 | 0.4 / 0.2 / 0.2 s |
| 8 | 恒等成立 | 0.9 s |

另外两条有了手算证明（写在论文草稿里）：
- **定理 2**：把共面行列式第 i 行乘 p_i t_i，问题化成 (x_i³ − e₁x_i²) ∈ span{1, x_i, 1/x_i}（x_i = 1/t_i）；再乘 x_i 就是 x_i⁴ − e₁x_i³ = −e₂x_i² + e₃x_i − e₄，即 ∏(x − x_j) 在根上为零。
- **定理 9**：以 T_ij 为心反演，过 T_ij 的球变成平面，与两个 Soddy 球的像正交 ⇔ 过它们的球心；两球心连线过 c_k c_l 的中点，即 T_kl 的像。不需要 (a)。

`C1/c1_lemma.py`：定理 11 用的一般四面体引理（直线 FF* 的刻画）中关键的一步，F* 满足 (F* − F)·u_k ∝ 1/d_k − W/4。以 Fermat 点处的单位向量 (±x, ±y, ±z) 为参数（对棱张角相等），在 x² + y² + z² = 1 下符号核对，6 个 2×2 子式恒为 0，1.1 秒。
