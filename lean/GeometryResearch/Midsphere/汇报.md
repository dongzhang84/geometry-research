### 定理 4 的方案（已完成，见上）

所有点都在平面 OMG 上；取 n = λv，v 是 OG 垂直于 OM 的分量，λ = (R² − |OG|²)/(2|v|²)，球心 O + n、半径² = R² + |n|²。A、B 因 n ⊥ OM 而在球上，2O − G 决定 λ，G′ 随之自动在球上；剩下 K′ 一条有理恒等式 (|OK′|² − R²)|v|² = (R² − |OG|²)⟪K′ − O, v⟫（论文 (eq:four)）。sympy 算出 |OG|²、|OK|²、R² 等闭式都是 14–16 次多项式，这条恒等式在 Lean 里规模较大，本轮没有做。

### 定理 5 的做法（已完成）

直接算 5 点的行列式太大（sympy 十分钟算不出 4×4 行列式）。更好的路线：T₁₂ 与两个 Feuerbach 点都在棱切球 μ 上（面的内切圆就是 μ 与面所在平面的交线），所求的球取 μ 与过这三点的平面 Π 所生成的球束里的一个；弦中点 N 对 μ 的幂为 −(半弦长)²，于是条件化为一条小恒等式 |T₀₂T₁₃|²·(ℓ(T₀₁) + ℓ(T₂₃)) = |T₀₁T₂₃|²·(ℓ(T₀₂) + ℓ(T₁₃))，ℓ 是 Π 的仿射方程。需要另行处理 r₁ = r₂（三点重合为 T₁₂）等退化情形。

实现要点：平面 Π 写成 ℓ(X) = Σ Lᵢ·xᵢ（`ellV`），Lᵢ 取使 ℓ 在 T₁₂ 与两个 Feuerbach 点上为零的值（`Lv`）。X₁₁ 在 μ 上（`aW_on`、`bW_on`）与核心恒等式（`key5`）都是 rᵢ 的有理恒等式，`field_simp; ring` 几秒内完成。若 ℓ(N₀₁|₂₃) ≠ 0，取球 |X − M|² − ρ² + λℓ(X) = 0（λ = |T₀₁T₂₃|²/(4ℓ(N₀₁|₂₃))）；否则由核心恒等式 ℓ(N₀₂|₁₃) 也为零，五点都在 Π 上。r₁ = r₂ 时两个 Feuerbach 点都与 T₁₂ 重合，只剩三点。
注意：Feuerbach 点用的是论文的重心坐标定义；它确实是面上九点圆与内切圆的切点这一忠实性引理 `X11_faithful` 仍未证。

### 定理 3 的做法（已完成）

论文用以 T₁₂ 为中心的反演。形式化改用与定理 5 相同的球束：T₀₁、T₀₂、T₁₃、T₂₃ 在 μ 上，也在平面 ℓ = r₀x₀ − r₁x₁ − r₂x₂ + r₃x₃ = 0 上（`L3`）。Soddy 球 (Sₖ, ρₖ) 与 Σᵢ 的切点对 μ 的幂是 rᵢ(Pₖ − ρₖ²)/(rᵢ + ρₖ)（`spt_pow`，Pₖ 为 Sₖ 对 μ 的幂），ℓ 值是 rᵢ(ℓ(Sₖ) ∓ ρₖ)/(rᵢ + ρₖ)。所以只需一个 λ 同时满足两条线性方程，相容条件 (P₁ − ρ₁²)(ℓ(S₂) + ρ₂) = (P₂ − ρ₂²)(ℓ(S₁) − ρ₁) 用 Soddy 方程化简后就是 1/ρ₁ + 1/ρ₂ = s（两个 Soddy 曲率之和，`soddy_sum`）。两个系数都为零时八点都在平面 ℓ = 0 上。

### 定理 10 的做法（已完成）

论文用以 T_kl 为中心的反演。形式化改用代数方法：先证 (i j | k l) = (0 1 | 2 3)，再对单形重新编号（`perm4`、`ofW_reindex` 等）得到一般情形。

所求的球写成 pow_σ(X) + ℓ(X) = 0（σ 为 Soddy 球，ℓ 仿射，`L10` 给出它在顶点上的值）。pow_σ 用 Lagrange 公式 |XY|² = Σxₐ|VₐY|² − ½ΣΣxₐx_b e_ab 计算（`dist_ofW_pt`）。两个切点在 σ 上，ℓ 在它们上为零。Z、N 的条件是 rᵢ、ρ 的有理恒等式，不需要 Soddy 方程。对 M′ = ι_σ(M)，pow_σ(M′) + ℓ(M′) = (pow_σ(M)(ℓ(S) − ρ²) + ρ²ℓ(M))/|MS|²（`inv_comb`），分子等于 4ρΠW/(3D·e₃·(2Π − ρe₃)) 乘 Soddy 方程 Q(ρ)。

ℓ 的表达式有 1/(r₀ − r₁)。r₀ = r₁ 时交换 V₀、V₁ 的反射保持五点不动，五点都在平面 x₀ = x₁ 上，归入「或共面」。所以证明没有用到「四面体不是正四面体」这一假设（陈述保留了它，与论文一致）。

### 定理 6、7 的做法（已完成）

- 面的内心：Mathlib 的内心权重是 1/hᵢ。由 `height_eq_sin_mul_dist`（hᵢ = sin(角)·边）得 hᵢ·aᵢ 都等于两倍面积，所以权重与对边长成正比（`incenter_eq`）；对切长为 r 的面就是 (r_b + r_c : r_a + r_c : r_a + r_b)（`Ipt3_eq`、`Ipt1_eq`）。
- m₀₂ 到直线 V₁V₃ 的垂足用 `coe_orthogonalProjection_eq_iff_mem` 写成 lineMap（`proj_line`、`foot02_eq`）。
- 广义球判据（`Gq`、`mcosph_of_Gq`）：点集满足 α(−½xᵀEx) + Σpₐxₐ = 0，α ≠ 0 时共球，α = 0 且 p 不是常数时共面。
- 定理 6 的 p 有 1/(r₁ − r₃)；r₁ = r₃ 时五点在平面 (r₀ + r₁)x₀ − (r₁ + r₂)x₂ = 0 上。定理 7 的 p 有 1/(r₀ − r₂)；r₀ = r₂ 时五点在 x₀ = x₂ 上。

各点的条件都是 rᵢ 的有理恒等式，`field_simp; ring` 几秒内完成。

### `X11_faithful` 的做法（已完成）

- 九点圆：Mathlib 的九点圆过三条边的中点（`faceOppositeCentroid_mem_ninePointCircle`）。设 qₘ = |VₘN|²，三个中点在圆上给出三条线性关系；由 Lagrange 公式，面上点在圆上化为一条重心坐标恒等式（`nine_face`）。
- 内切圆：由 hᵢ = sin(角)·边与余弦定理得 inradius² = (b²c² − ((b² + c² − a²)/2)²)/(a + b + c)²（`inradius_sq`），对切长为 r 的面是 r_a r_b r_c/(r_a + r_b + r_c)（`inr_face`）。|X₁₁I|² 用重心坐标算出相同的值。
四个面各验证两条有理恒等式（`X11_main`）。
